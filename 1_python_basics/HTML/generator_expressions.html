📊 Key Differences

Syntax Difference:
List Comprehension: [x**2 for x in range(10)] uses square brackets [ ]
Generator Expression: (x**2 for x in range(10)) uses parentheses ( )

✅ List Comprehension Benefits:

• All items available immediately
• Can iterate multiple times
• Can access by index
• Can get length with len()
• Fast random access

✅ Generator Expression Benefits:

• Memory efficient (one item at a time)
• Great for large datasets
• Perfect for pipelines
• Can represent infinite sequences
• Lazy evaluation (compute on demand)

⚠️ List Comprehension Drawbacks:

• Uses more memory
• All items computed upfront
• Not suitable for very large datasets
• Can't represent infinite sequences

⚠️ Generator Expression Drawbacks:

• Items consumed once (can't reuse)
• Can't access by index
• Can't get length directly
• Slightly slower per-item access
• Must iterate sequentially
