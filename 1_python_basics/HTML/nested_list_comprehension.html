📊 Creating a 2D Matrix

# Create a 3x3 multiplication table # Nested list comprehension matrix = [[i * j for j in range(1, 4)] for i in range(1, 4)] # Equivalent nested loops: matrix = [] for i in range(1, 4): # Outer loop row = [] for j in range(1, 4): # Inner loop row.append(i * j) matrix.append(row)
💡 Reading Order: In nested list comprehensions, read from RIGHT to LEFT for the loop order. The rightmost for is the outer loop, the leftmost is the inner loop.

📦 Flattening Nested Lists

# Flatten a 2D list into a 1D list nested_list = [[1, 2, 3], [4, 5, 6], [7, 8, 9]] # Nested list comprehension flat = [num for row in nested_list for num in row] # Result: [1, 2, 3, 4, 5, 6, 7, 8, 9] # Equivalent nested loops: flat = [] for row in nested_list: # Outer loop - iterate rows for num in row: # Inner loop - iterate items in row flat.append(num)

🔍 Nested List Comprehension with Conditions

# Create a matrix with only even products # Nested list comprehension with condition matrix = [[i * j for j in range(1, 6) if (i * j) % 2 == 0] for i in range(1, 6)] # Equivalent nested loops: matrix = [] for i in range(1, 6): row = [] for j in range(1, 6): if (i * j) % 2 == 0: # Only even products row.append(i * j) matrix.append(row)

🔄 Nested Loops vs List Comprehension

Aspect Nested Loops Nested List Comprehension
Syntax Multi-line, explicit Single line, compact
Readability Easier for beginners More Pythonic, but needs practice
Performance Slightly slower Slightly faster (optimized)
Use Case Complex logic, debugging Simple transformations, filtering
Lines of Code 5-6 lines 1-2 lines

📝 Common Patterns

Pattern 1: Create 2D Grid

# 4x4 grid of zeros grid = [[0 for _ in range(4)] for _ in range(4)]

Pattern 2: Coordinates

# All (x,y) pairs coords = [(x, y) for x in range(3) for y in range(3)]

Pattern 3: Flatten with Transform

# Square all numbers squared = [x**2 for row in matrix for x in row]

Pattern 4: Conditional Filtering

# Only positive evens result = [x for row in matrix for x in row if x > 0 and x % 2 == 0]
🎯 Best Practice: Use nested list comprehensions for simple operations. For complex logic with multiple conditions or transformations, regular nested loops are more readable and maintainable.
