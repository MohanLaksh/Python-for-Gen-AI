Use cases

1️⃣ Mainframe (International Transportation Domain)
Use Case: Shipment Delay Root Cause Analyzer
Problem
* COBOL/JCL batch jobs generate logs
* Delays occur in cross-border cargo movement
* Hard to manually analyze job failures + logistics notes
Project
* Input: Mainframe batch logs + shipment notes
* LLM summarizes:
    * Root cause
    * Impacted countries
    * Suggested corrective action
LLM Wrapper Usage
* Log summarization
* Incident explanation in plain English
* Auto-generate escalation email
Value
* Bridges legacy mainframe + modern AI
* Reduces MTTR for logistics delays
